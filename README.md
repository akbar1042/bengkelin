# bengkelin
Bengkelin adalah platform yang dapat membantu:
1. Customer:
   1) Menemukan bengkel terdekat
   2) Mendapat bantuan ketika terjadi mogok di tengah jalan dan kesulitan mencari bengkel maupun kesulitan mendapat bantuan derek
      
2. Bengkel (Mitra):
   1) Mempermudah penjualan jasa terhadap pelanggan
   2) Menaikkan nama dan reputasi bengkel agar lebih mudah dikenal oleh pelanggan
